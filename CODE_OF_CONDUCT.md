# Code of conduct

Treat participants respectfully. Keep technical disagreement focused on evidence
and code. Harassment, threats, discrimination, disclosure of private information
and deliberate disruption are not acceptable.

This applies to project-managed discussions, issues and pull requests in this repository. Authors of a contribution should accept feedback and help correct
unintended harm. No private reporting contact or designated enforcement team has
been appointed. For a public concern, use an issue containing only non-sensitive information; do not publish sensitive allegations or personal data in a public issue.
No response deadline or appeal procedure is promised by this draft.
