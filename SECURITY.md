# Security policy — preparation status

The current public release is 1.0.0. No private reporting channel has been designated.
There is no security audit or vulnerability-free guarantee. No response deadline or long-term support commitment is promised.

Do not post exploit details, secrets, player profiles or private system data in
public issues. Before sharing sensitive information, agree on a private route
with the author. No address, contact identity or response deadline is invented
here. Selecting a private reporting route and public support scope is a decision
required before public issue tracking is enabled.

Binary candidates are unsigned. Download only an approved release, verify its
published SHA-256, keep operating-system protections enabled, and follow
[INSTALL_WINDOWS](docs/INSTALL_WINDOWS.md). A checksum verifies integrity relative
to its trusted source; it is not proof of harmlessness or an authentic signature.
