# Changelog

## 1.0.0 — 2026-11-08

First public release of Q*Bert Pyramid (QBERT Rev. 1.0): complete game, original
art/event audio, configurable controls/settings, profile migration and local top
ten. Includes About and original player-derived application icons. Windows x64
package, matching editable sources, tests and build scripts are supplied.
The public repository begins here; private development history is not included.
