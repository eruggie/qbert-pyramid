# Project phases and release scope

| Phase | Description |
|---|---|
| 1 | Board, jumps, controls and color rules |
| 2 | Lives, scores, respawn and initial rounds |
| 3 | Opponents, collisions, discs, Stasis and continuous progression |
| 4 | Art, event audio, menus, settings and local persistence |
| 5 | Windows packaging, corresponding source and reconstruction |
| 6 | |
| 7 | Open-source publication and GitHub release of version 1.0.0 |

This public repository begins with the reviewed 1.0.0 snapshot, not the private
historical development commits. The owner has accepted phase 6, the final menu
and sprite-derived icons. Phase 7 publication is tracked in docs/PHASE7.md.
Historical packages and reference media are not part of the public source tree.
