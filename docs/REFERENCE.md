# Reference works and credits

The Gottlieb Q*bert instruction manual (11-82) was consulted as the primary
rules reference; it is not distributed. User-provided gameplay recordings
were consultation only and are not included. Some sound comparisons used
numerical duration/spectral measurements rather than perceptual listening.
No ROM, Flash file, copied sprite, recording or reference capture is required.

Thanks to Warren Davis and Jeff Lee at Gottlieb. References:

- https://www.classicgamesarcade.com/italiano/game/21652/q-bert.html

The linked JavaScript/canvas project is a separate implementation, not a source
of incorporated code or assets. A reference link does not transfer a license.
