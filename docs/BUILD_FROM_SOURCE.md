# Build from source

## Supported development route

Windows host -> Ubuntu 22.04 x86_64 under WSL2 -> Bash and Godot standard Linux.
VS Code with Remote WSL/Godot tooling is optional. A native Windows build of these
Bash scripts, a Linux binary release and other platforms are not verified.

Official prerequisites: [WSL](https://learn.microsoft.com/en-us/windows/wsl/install),
[Git](https://git-scm.com/downloads), [Python](https://www.python.org/downloads/),
[VS Code](https://code.visualstudio.com/docs/remote/wsl), and
[Godot archive](https://godotengine.org/download/archive/).
No installation is run automatically. Bash >=5.1, Python >=3.10 standard library,
Git >=2.34, zip, unzip, timeout, SHA-256 and standard coreutils are required.

Install Godot **4.7.2 standard**, exact build 4.7.2.stable.official.ed1daf0bf,
and matching 4.7.2.stable export templates, including Windows x86_64 release
and debug. Hashes are in tools/toolchain.json. Put Godot on PATH or set GODOT_BIN;
templates normally live at ~/.local/share/godot/export_templates/4.7.2.stable/.
GODOT_TEMPLATE_DIR can select their directory explicitly. No C# SDK is required.

## Obtain an approved revision

Clone the public tag from the WSL Bash terminal (not PowerShell):

```bash
git clone https://github.com/eruggie/qbert-pyramid.git
cd qbert-pyramid
git checkout --detach v1.0.0
```

Alternatively extract the corresponding-source release ZIP into a new folder:

```bash
git clone BASE.bundle work
cp -a source/. work/
cd work
sha256sum -c ../SOURCE_FILES.sha256
```

The published source tree is committed in full; the source archive manifest
binds the exact files to its public commit. BASE.bundle contains only the new
public history, with no private predecessor commits or unlicensed supplied icons.

## Open, test and export

```bash
godot --editor --path .
bash tools/doctor.sh
bash tools/test.sh
bash tools/smoke_linux.sh
bash tools/build_windows.sh
```

The graphical smoke requires WSLg. The build already runs doctor and full tests;
run commands individually when diagnosing or making the documented checks, not
as an unexplained repeated gate. Negative runner modes must exit nonzero:
`bash tools/test.sh --self-test-empty` and `--self-test-failure`.
All public scripts work from other working directories using their full paths.

Outputs under builds/ contain EXE/PCK, documents, licenses, metadata, checksums
and a source ZIP with Git base, working-tree overlay and source manifest. Temporary
profiles/logs/cache live under .local-state/. Scripts do not install dependencies
or alter global configuration. Preserve .uid and .import resource descriptors;
do not commit generated .godot/ cache or binaries. Asset synthesis sources are
tools/generate_audio.py and tools/generate_arcade_art.py; the application PNG/ICO are generated by tools/generate_app_icon.py from the
same original sprite. Historical supplied icons remain an upload exclusion,
as described in LICENSING.md.

BUILD_INFO.json and SOURCE_FILES.sha256 bind a package to its actual snapshot,
including uncommitted changes. Do not identify a dirty snapshot solely by HEAD.
Reconstruction is supported; byte-for-byte equality of timestamped binaries and
ZIPs is not promised. A clean public tag must be built and tested again after
history/publication decisions. No assistant account or Codex tool is required.
