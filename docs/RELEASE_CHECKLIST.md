# Release checklist

## Local preparation

- [x] Record current sources, previous artifact and read-only owner/name checks.
- [x] Prepare English README, installation/build guides, notices, policies,
  changelog, citation, issue/PR templates and separate catalog materials.
- [x] Keep original-language historical evidence; do not alter gameplay.
- [x] Run the read-only history/account audit; record exact local artifacts/hashes
  in the delivery report before proposing any upload.

## Gates before approval of any public upload

- [x] Record owner-directed phase 6 closure and latest-menu Windows acceptance.
- [x] Record owner-directed performance acceptance; no numerical frame data supplied.
- [x] Replace current supplied ICO/JPEG with original sprite-derived PNG/ICO.
- [ ] Clear historical supplied icon blobs before uploading source history/BASE.bundle.
- [ ] Obtain owner acceptance of the newly tested icon build.
- [ ] Author chooses publication of existing commit email/private historical paths,
  or approves a separate screened public history; no automatic rewriting.
- [x] Confirm personal owner and create only eruggie/qbert-pyramid and eruggie/80-arcade-games empty.
- [x] Owner approved public version 1.1.0, source/tag and upload.
- [ ] Select private security/conduct/rights-reporting routes and support scope.
- [ ] Verify all proposed upload files/history contain no secrets or uncleared material.
- [x] Review exact sources, release artifacts, hashes and remote operation list.
- [x] Owner explicitly authorized commit, tag, public release and private backup synchronization.

## After authorized publication

- [x] Game repository updated under confirmed personal account; catalog remains separate.
- [x] Tag identifies exact release source tree; licenses/attributions/links coherent.
- [x] Installer, binary ZIP, corresponding sources, build metadata and checksums downloadable.
- [x] Owner reports Windows 11 x86_64 manual testing complete.
- [x] Clean public tag tested and built using BUILD_FROM_SOURCE.md.
- [ ] Catalog links the actual game repository; README links the actual release.
- [x] Record actual URLs and distinguish Windows, automatic and owner-reported evidence.

Phase 7 public release 1.1.0 completed on 2026-11-09; see docs/releases/v1.1.0.md. Historical gates describe the prior 1.0.0 preparation.
