# Publication snapshot audit

The public repository is initialized from reviewed current 1.0.0 files only.
Its initial source commit has no parents; no previous private development
commit, old icon/JPEG, historical archive, reference media or private author
email is imported. New public commits use GitHub's noreply identity.

Source files are scanned for credential patterns and personal email before
publication. All original runtime scripts, scenes, audio, atlas and current
player-derived icons match the owner-approved local source snapshot. The full
source archive's BASE.bundle contains only the new public release history.
Private history/backups are stored separately and are not release assets.
A pattern scan is not a full security audit or a guarantee of harmlessness.
