# Current audiovisual behavior

Original isometric board, generated pixel sprites/font and distinct per-round
palettes are rendered by the project's own presentation code. The fourteen
short, non-looping event effects are synthesized from original oscillators,
deterministic noise and envelopes. Their generator and PCM integrity tests
are supplied. No continuous music or original arcade samples are used.

Reference gameplay informed event roles, durations and rhythm where measurable;
exact perceptual identity with the original arcade is not claimed. Event mapping,
one-shot behavior, overlapping transitions and cancellation on pause/focus/scene/
restart are tested. Current app icons use the original in-game player sprite.
Windows menu and icons were accepted by the owner; see VALIDATION.md.
