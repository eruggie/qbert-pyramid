# Phase 7 — public release 1.0.0

Authorized scope: publish the current reviewed version, create its initial public
commit/tag and release assets, populate the personal arcade catalog, and retain
the full original history in a separate private backup. No gameplay/port changes.

The public game repository has a fresh history beginning with 1.0.0; the catalog
is separate. Old source history, ZIPs and consultation materials are not imported.
Release gates include source/privacy/license checks, exact-tag build, matching
corresponding sources, verified public downloads, clean checkout reconstruction
and Windows EXE launch. Results are recorded in VALIDATION and the validation
asset attached to the release. Creating a repository alone is not completion.
