# Q*Bert Pyramid 1.0.0 — QBERT Rev. 1.0

First public source snapshot and Windows 11 x86_64 release of this independent,
unofficial arcade game by Eugenio Ruggieri. Original code/assets: GPL-3.0-only.

Hop across 28 tiles with Q/E/Z/C, arrows or keypad 7/9/1/3. Includes three color
rules, four enemy roles, rescue discs, moving green pickup, continuous progression,
original event sounds, settings and local top-ten results. About includes author,
license and instructions. App/window/menu icons derive from the original player.

Download QBertPyramid-1.0.0-Windows-x86_64.zip and its SHA-256 file. Verify, extract
all files and run QBertPyramid.exe; keep PCK/licenses beside it. No Godot, WSL,
Python, Git, VS Code or coding assistant is needed by players. EXE is unsigned;
keep Windows protections enabled. Data stays in %APPDATA%/QBertPyramid.

Automatic baseline: 126 GDScript tests / 126546 assertions and 17 Python tests,
PCK/ZIP/source checks. WSLg graphics and owner-reported Windows acceptance are
separate evidence. The owner accepted final menu/icons and phase 6, including
performance. No raw frame-time samples/numerical results were supplied here;
there is no universal hardware/FPS guarantee. Validation assets record the final
public download, Windows launch and clean public-tag rebuild checks.

Windows 10, ARM, Web and Android releases are not claimed. Private historical
versions/media are not included; the public history begins with this release.
Corresponding sources and editable asset generators accompany the binary.
