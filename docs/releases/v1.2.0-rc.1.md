# Q*Bert Pyramid Web 1.2.0-rc.1 — candidata locale

Port Web desktop della versione classica pubblica 1.1.0, Godot 4.7.2 standard,
renderer Compatibility e export senza thread. Gameplay, progressione, punteggi,
collisioni, immagini e suoni del tag classico mantenuti. Escher e piattaforme
mobile/touch sono esclusi.

Aggiunge preset e build Web riproducibile, pagina dedicata sotto
`/80_arcade_games/qbert/`, avvio esplicito, focus/pausa, link di andata/ritorno,
alias fisici per conservare il tastierino, fallback dei simboli e avvisi sulla
persistenza locale. Font di terzi con licenza propria inclusa.

[Procedura](../WEB_PORT.md), [verifiche e limiti](../WEB_VALIDATION.md),
[hosting gratuito e fonti](../WEB_HOSTING.md). Non è una release stabile:
fullscreen, ascolto e accettazione manuale estesa restano aperti.
Non pubblicata e non autorizzata alla pubblicazione. Windows v1.1.0 invariata.
