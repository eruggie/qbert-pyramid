# Q*Bert Pyramid 1.1.0 — QBERT Rev. 1.1

**Release date:** 2026-11-09
**Tag:** `v1.1.0`
**Platform:** Windows 11 x86_64

This release updates the Coil collision presentation and adds an optional
per-user Windows installer. The public 1.0.0 release remains available in its
original tag.

## Changes

- When Coil kills Q*BERT, the replacement image is rendered at exactly the same
  40×48 atlas-frame destination size, scale and feet anchor as the regular
  player sprite. The source image is kept intact; the renderer scales it for the
  game frame at every board position and supported viewport size.
- A single supplied voice cue plays for Coil capture. The original 90-tick
  death interval, collision and scoring rules, input, protection and Stasis are
  preserved.
- Windows EXE file properties identify Eugenio Ruggieri and `(c) Eugenio
  Ruggieri 2026`. The installer has publisher metadata as well; neither file is
  Authenticode-signed.
- The NSIS installer targets the current Windows user, needs no administrator
  access or extra downloads, adds Start menu shortcuts and registers for removal
  in Windows Settings. Uninstall preserves game saves and user-added files.
- Downloadable outputs: installer, portable runtime ZIP, corresponding source
  ZIP and SHA-256 sums. Source and binary downloads are provided as separate
  release assets, with the public source tag identifying the matching project.

## Downloads and verification

Use the Windows 11 x86_64 assets attached to the GitHub release. Check the
matching entry in `QBertPyramid-1.1.0-SHA256SUMS.txt` before running downloads.
For the portable edition extract the complete ZIP. The installer and portable
edition both include the game runtime and licenses; players do not need Godot,
Python, Git, WSL or developer tools.

The owner confirms authority to redistribute the supplied Coil image and audio
under the project GPL-3.0-only terms. Their provenance and scope are recorded in
[ASSET_LICENSES.md](../ASSET_LICENSES.md). The full GPL and third-party notices
ship with the downloads.

Automated validation: 129 GDScript tests, 126766 assertions, 12 source/package
regression tests and 6 asset tests passed. Windows export, all three isolated
PCK scenes/resources, Linux X11 graphics capture and PulseAudio device delivery
passed. The owner reports that manual testing on Windows passed on 2026-11-09.
The manual Windows test was performed by the owner; no further hardware or
session details are asserted here.

**Windows security:** EXE and installer are unsigned. The embedded author field
is file metadata, not proof of publisher identity. Windows SmartScreen may still
warn about a downloaded release; do not disable Windows security protections.
