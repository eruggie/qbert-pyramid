# Current asset catalog

| Resource | Origin / editable source |
|---|---|
| assets/arcade/actors.png | Original procedural sprites, tools/generate_arcade_art.py |
| assets/arcade/arcade_font.png and .fnt | Original bitmap alphabet, same generator |
| Board, discs, palettes and animation | Original scripts/presentation code |
| Fourteen assets/audio WAV effects | Original mathematical synthesis, tools/generate_audio.py |
| assets/ui/qbert.png and qbert.ico | Same player sprite, tools/generate_app_icon.py |
| docs/screenshots/gameplay.png | Rendered product screenshot, provenance beside image |
| Fallback font and engine components | Godot; complete notices in THIRD_PARTY_NOTICES.txt |

No original arcade ROM, Flash file, reference image, video or extracted sound is
included. The icon generator uses only the standard library, centered transparent
padding and nearest-neighbor resizing. The legacy original geometric SVG remains
an original project asset, not an external supplied image.
